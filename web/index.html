    FROM BEHAVIOR TO A RANKED SHELF

    How your recommendations are made.

    The same feature and retrieval code runs during evaluation and in this demo.

    01 / LEARN

    Implicit behavior

    Views, carts and purchases form a sparse user-item matrix. ALS learns 32-dimensional item factors from the earlier period.

    02 / RETRIEVE

    Find candidates

    Combine up to 60 ALS items, 60 similar items and 20 popular items. Products in the recent history are excluded.

    03 / RANK

    Learn the order

    LightGBM LambdaMART uses 12 features, including similarity, popularity and historical cart/purchase ratios, to reorder candidates.

    04 / SERVE

    Respond to actions

    FastAPI serves recommendations. SQLite keeps this demo session's actions and impression records. Empty profiles fall back to popularity.

    Reused algorithms, project-specific engineering

    ALS is provided by the open-source Implicit library. LambdaMART is provided by LightGBM. RetailRank adds data preparation, chronological splits, candidate blending, ranking features, evaluation, session APIs and this interactive demo.
